# درب | DARB Studio
موقع معرض أعمال عربي متجاوب لخدمات التصميم، مع أزرار واتساب مباشرة برسائل مسبقة التعبئة.

## الملفات
- `index.html` صفحة الموقع
- `styles.css` أنماط التصميم المتجاوب
- `script.js` روابط واتساب وفلاتر معرض الأعمال
- `assets/` الشعارات التي زودني بها صاحب الموقع وموك أب تصوري لها

## معاينة محلية
افتح `index.html` في متصفح. يتطلب اتصالًا بالإنترنت لتحميل خط Google Fonts، وكل الوظائف الأساسية تعمل دون خادم.

## تشغيل روابط واتساب
الرقم مهيأ على 966566366401. اختبر الروابط من الجوال قبل النشر.

## ملاحظات على المعرض
الشعارات الأصلية محفوظة كملفات مستقلة؛ صور `project-*.jpg` موك أب تصوري وليست صورًا لمنتجات مطبوعة فعلية. يجب الحفاظ على هذا التوضيح لتجنب إيهام الزوار. راجع أسماء المشاريع وموافقات العملاء قبل عرضها علنًا.

## النشر عبر GitHub Pages
1. أنشئ مستودع GitHub باسم `darb-studio`.
2. ارفع كل محتويات هذا المجلد إلى الفرع `main`.
3. من Settings > Pages، اختر Deploy from a branch، ثم `main` و`/ (root)`.
4. انتظر نجاح النشر ثم استخدم الرابط الذي تعرضه GitHub Pages.
